# Vision

AethyxLM is a decoder-only transformer language model built from scratch to understand every major component of a modern Large Language Model.

The goal is not merely to reproduce an existing model, but to design, implement, train, evaluate, and continuously improve a family of language models while understanding every engineering decision behind them.

---

# Mission

Build a family of efficient language models capable of:

* Natural conversation
* Code generation
* Logical reasoning
* Scientific understanding
* Educational explanations

while remaining lightweight, transparent, and completely documented.

---

# Core Principles

* Build before optimizing.
* Understand every line of code.
* Prefer simplicity over unnecessary complexity.
* Document every major design decision.
* Scale gradually.
* Never sacrifice understanding for speed.
